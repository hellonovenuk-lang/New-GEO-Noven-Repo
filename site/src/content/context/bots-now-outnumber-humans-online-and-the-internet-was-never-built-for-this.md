He'd expected bots to pass human traffic by the end of 2027, and it happened eighteen months early. For a Wardith client the point is the one behind everything else this repo tracks: the visitor reading a page today is often software building an answer for someone else, so a page has to hold up as a source an agent can read, not only as a page a person can browse."

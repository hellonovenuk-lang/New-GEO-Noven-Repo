# The operating documents — index

The files in this folder have no obvious order to read them in. This is the
order.

New to the business? Read `HANDOVER.md` at the repo root first. It is the only
document written for someone with no context.

**Status vocabulary**, used below and worth adding to each file's header:

- **Live** — describes something that exists and is working.
- **Decided, unvalidated** — a decision written down, never yet performed. The
  most common status here, and the one most easily mistaken for the one above.
- **Closed** — the job it describes is finished; kept for reference.
- **Stub** — a title and a TODO.
